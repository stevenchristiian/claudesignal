**This is the second consecutive run where the margin narrowed while BNB worsened, and this time it moved
the score.** The written rule fired and the written rule is what moves scores here, so the move stands and
was published — but the branch is now demonstrated to be capable of restoring a handicap on evidence that
confirms the handicap. **Do not patch it retroactively.** Options for the user, in the order this run would
rank them:

1. **Require the subject to contribute.** Fire only if BNB's own return moved in the same direction as the

2. **Compare like-for-like windows.** Measure the margin change only across days that are in *both*

3. **Lengthen the window** to 14 or 21 days so a single session's roll-off moves the median less. The
   Sept 25 note argued against this on the evidence then available; the diagnosis today is the same
   (a median of five is noisy to roll-off), and this is the blunter fix.
