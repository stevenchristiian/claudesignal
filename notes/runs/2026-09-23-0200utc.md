**One assertion failed and it was the assertion's fault, audited before touching `index.html`.**
Check 2 reported `COINS is not defined`. The cause was JavaScript scoping in the *validator*, not a
defect in the file: a direct `eval()` of a `const` declaration creates its own lexical environment, so
the arrays never reached the outer scope. `node --check` had already passed on the same script.

6/6/21/18. **This is the fourth consecutive run where a first-pass validation failure was the harness
and not the build** — the checklist rule to audit the assertion before editing the file has now paid
for itself four times.

superlative, count, margin and ordering — were re-derived from the tape JSON and the Farside rows and
all 45 held. The three orderings inside the noise floor had already been declined at drafting.
